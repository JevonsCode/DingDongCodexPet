# DingDong Codex Pet

A Codex v2 animated pet adapted from the approved DingDong mascot artwork.

<p align="center"><em>A cheerful navy-and-orange helper for Codex.</em></p>

## Package contents

- `pet.json` — portable pet metadata using a relative spritesheet path.
- `spritesheet.webp` — the validated 8×11 animation atlas (`1536×2288`, 192×208 cells).
- `preview.png` — a README-only preview extracted from the validated idle animation.

## Install locally

Copy this directory to the `pets/dingdong` folder inside your Codex home directory. Keep `pet.json` and `spritesheet.webp` together.

## Publishing

This package intentionally contains no absolute filesystem paths, usernames, machine identifiers, repository locations, generation prompts, or local QA metadata. Add an appropriate license before distributing it publicly.
